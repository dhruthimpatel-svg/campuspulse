# CampusPulse 📚

CampusPulse is a **prototype BNMIT digital campus companion** designed to bring campus events, clubs, announcements and resources into one place.

🚧 **Current Status:** This is a working prototype/demo. The UI and core features are built, but the platform is **not yet fully connected to live campus data**, so some content is currently static/mock data.

### 🎯 Goal

To create a centralized platform where students can easily discover what's happening around campus.

### 🛠️ Built With

* HTML, CSS & JavaScript
* Supabase
* Manus

### 🚀 Future Plans

* Connect real-time campus data
* Live event and announcement updates
* Admin dashboard for managing content
* More BNMIT-specific features
